PICALL 1.2.4
==========

Быстрая локальная медиатека фото и видео для Windows.

• Picall автоматически просматривает локальные и съёмные диски.
• Найденные файлы появляются в галерее, а индекс сохраняется для быстрого запуска.
• Новые, изменённые и удалённые файлы отслеживаются автоматически.
• Двойной щелчок открывает файл в приложении Windows по умолчанию.
• Правый щелчок позволяет перейти к файлу в Проводнике и добавить его в избранное.
• Ctrl+F — поиск, F5 — повторное сканирование, Esc — очистить поиск.

Все данные остаются на компьютере. Индекс и кэш превью находятся в:
%LOCALAPPDATA%\Picall

Для запуска требуется Microsoft Windows Desktop Runtime 8 или новее.
