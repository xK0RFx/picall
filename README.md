# Picall

Picall — быстрая локальная медиатека для Windows. Приложение автоматически находит фотографии и видео на локальных и съёмных дисках, показывает их в виртуализированной сетке и обновляет каталог при изменениях файловой системы.

## Возможности

- фоновое индексирование всех доступных локальных дисков;
- сохранённый индекс: повторный запуск показывает медиатеку сразу;
- ленивые превью изображений и видео через системные кодеки Windows;
- живое появление, изменение и удаление файлов без ручного обновления;
- поиск по имени, папке или расширению;
- фильтры фото, видео и избранного;
- выбор конкретного диска или добавленной папки;
- фильтры по формату, дате изменения и размеру;
- встроенные превью JPEG XL, AVIF, HEIC, WebP, JPEG 2000, RAW и десятков других форматов;
- сортировка и изменение масштаба карточек;
- открытие файла и переход к нему в Проводнике;
- полностью локальная работа без аккаунта и отправки данных.

## Управление

- двойной щелчок или `Enter` — открыть файл;
- правый щелчок — открыть, показать в Проводнике, скопировать путь или добавить в избранное;
- `Ctrl+F` — поиск;
- `F5` — пересканировать диски;
- `Esc` — очистить поиск.

Кэш и индекс хранятся в `%LOCALAPPDATA%\Picall`. Системные папки Windows и программ при полном сканировании диска пропускаются.

## Сборка

Запустите `powershell -ExecutionPolicy Bypass -File tools\Build-Release.ps1`. Готовые файлы появятся в `dist`.
